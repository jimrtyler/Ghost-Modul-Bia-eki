# 👻 Модуль Бяспекі Ghost
**Інструмент Узмацнення Бяспекі Windows і Azure на Аснове PowerShell**

> **Праактыўнае узмацненне бяспекі для канчатковых кропак Windows і асяроддзяў Azure.** Ghost забяспечвае функцыі ўзмацнення на аснове PowerShell, якія могуць дапамагчы паменшыць распаўсюджаныя вектары атак шляхам адключэння непатрэбных сэрвісаў і пратаколаў.

## ⚠️ Важныя Адмовы ад Адказнасці

**ТЭСТАВАННЕ НЕАБХОДНА**: Заўсёды спачатку тэсціруйце Ghost у непрадукцыйных асяроддзях. Адключэнне сэрвісаў можа паўплываць на законныя бізнес-функцыі.

**НІЯКАЙ ГАРАНТЫІ**: Нягледзячы на тое, што Ghost накіраваны на распаўсюджаныя вектары атак, ніводны інструмент бяспекі не можа прадухіліць усе атакі. Гэта адзін кампанент комплекснай стратэгіі бяспекі.

**АПЕРАЦЫЙНЫ ЎПЛЫЎ**: Некаторыя функцыі могуць паўплываць на функцыянальнасць сістэмы. Уважліва праверце кожную налада перад разгортваннем.

**ПРАФЕСІЙНАЯ АЦЭНКА**: Для прадукцыйных асяроддзяў кансультуйцеся са спецыялістамі па бяспецы, каб пераканацца, што налады адпавядаюць патрэбам вашай арганізацыі.

## 📊 Ландшафт Бяспекі

Страты ад ransomware дасягнулі **$57 мільярдаў у 2025 годзе**, даследаванні паказваюць, што многія паспяховыя атакі выкарыстоўваюць базавыя сэрвісы Windows і няправільныя канфігурацыі. Распаўсюджаныя вектары атак уключаюць:

- **90% інцыдэнтаў ransomware** уключаюць эксплуатацыю RDP
- **Уразлівасці SMBv1** дазволілі атакі накшталт WannaCry і NotPetya
- **Макрасы дакументаў** застаюцца асноўным метадам дастаўкі шкоднасных праграм
- **Атакі на аснове USB** працягваюць накіроўвацца на сеткі з паветраным зазорам
- **Злоўжыванне PowerShell** значна ўзрасло ў апошнія гады

## 🛡️ Функцыі Бяспекі Ghost

Ghost забяспечвае **16 функцый узмацнення Windows** плюс **інтэграцыю бяспекі Azure**:

### Узмацненне Канчатковых Кропак Windows

| Функцыя | Мэта | Меркаванні |
|----------|---------|----------------|
| `Set-RDP` | Кіруе доступам Remote Desktop | Можа паўплываць на аддаленае адміністраванне |
| `Set-SMBv1` | Кантралюе пратакол SMB спадчыны | Патрэбны для вельмі старых сістэм |
| `Set-AutoRun` | Кантралюе AutoPlay/AutoRun | Можа паўплываць на зручнасць карыстальніка |
| `Set-USBStorage` | Абмяжоўвае прылады захоўвання USB | Можа паўплываць на законнае выкарыстанне USB |
| `Set-Macros` | Кантралюе выкананне макрасаў Office | Можа паўплываць на дакументы з уключанымі макрасамі |
| `Set-PSRemoting` | Кіруе аддаленым доступам PowerShell | Можа паўплываць на аддаленае кіраванне |
| `Set-WinRM` | Кантралюе Windows Remote Management | Можа паўплываць на аддаленае адміністраванне |
| `Set-LLMNR` | Кіруе пратаколам вырашэння імёнаў | Звычайна бяспечна адключаць |
| `Set-NetBIOS` | Кантралюе NetBIOS праз TCP/IP | Можа паўплываць на спадчынныя прыкладанні |
| `Set-AdminShares` | Кіруе адміністрацыйнымі агульнымі рэсурсамі | Можа паўплываць на аддалены доступ да файлаў |
| `Set-Telemetry` | Кантралюе збор даных | Можа паўплываць на магчымасці дыягностыкі |
| `Set-GuestAccount` | Кіруе ўліковым запісам госця | Звычайна бяспечна адключаць |
| `Set-ICMP` | Кантралюе адказы ping | Можа паўплываць на дыягностыку сеткі |
| `Set-RemoteAssistance` | Кіруе аддаленай дапамогай | Можа паўплываць на аперацыі службы падтрымкі |
| `Set-NetworkDiscovery` | Кантралюе выяўленне сеткі | Можа паўплываць на прагляд сеткі |
| `Set-Firewall` | Кіруе Windows Firewall | Крытычна важны для бяспекі сеткі |

### Бяспека Воблака Azure

| Функцыя | Мэта | Патрабаванні |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | Уключае базавую бяспеку Azure AD | Дазволы Microsoft Graph |
| `Set-AzureConditionalAccess` | Наладжвае палітыкі доступу | Ліцэнзаванне Azure AD P1/P2 |
| `Set-AzurePrivilegedUsers` | Аўдыт прывілеяваных уліковых запісаў | Дазволы глабальнага адміністратара |

### Варыянты Разгортвання для Прадпрыемстваў

| Метад | Выпадак Выкарыстання | Патрабаванні |
|--------|----------|--------------|
| **Прамое Выкананне** | Тэставанне, невялікія асяроддзі | Правы лакальнага адміністратара |
| **Групавая Палітыка** | Асяроддзі дамена | Адміністратар дамена, кіраванне GP |

### Базавае Узмацненне (Спачатку Тэсціруйце)
```powershell
# Асноўное узмацненне - спачатку тэсціруйце ў лабараторным асяроддзі
Set-Ghost -SMBv1 -AutoRun -Macros

# Праверце змены
Get-Ghost
```

### Разгортванне для Прадпрыемстваў
```powershell
# Разгортванне групавой палітыкі (асяроддзі дамена)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# Разгортванне Intune (прылады, якімі кіруе воблака)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 Падрабязнасці Функцый

### Асноўныя Функцыі Узмацнення

#### Сеткавыя Сэрвісы
- **RDP**: Блакуе доступ да аддаленага працоўнага стала або рандамізуе порт
- **SMBv1**: Адключае спадчынны пратакол абмену файламі
- **ICMP**: Прадухіляе адказы ping для разведкі
- **LLMNR/NetBIOS**: Блакуе спадчынныя пратаколы вырашэння імёнаў

#### Бяспека Прыкладанняў
- **Macros**: Адключае выкананне макрасаў у прыкладаннях Office
- **AutoRun**: Прадухіляе аўтаматычнае выкананне са здымных носьбітаў

#### Аддаленае Кіраванне
- **PSRemoting**: Адключае аддаленыя сеансы PowerShell
- **WinRM**: Спыняе Windows Remote Management
- **Remote Assistance**: Блакуе злучэнні аддаленай дапамогі

#### Кантроль Доступу
- **Admin Shares**: Адключае агульныя рэсурсы C$, ADMIN$
- **Guest Account**: Адключае доступ уліковага запісу госця
- **USB Storage**: Абмяжоўвае выкарыстанне прылад USB

### Інтэграцыя Azure
```powershell
# Падключыцеся да арандатара Azure
Connect-AzureGhost -Interactive

# Уключыце значэнні па змаўчанні бяспекі
Set-AzureSecurityDefaults -Enable

# Наладзьце ўмоўны доступ
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# Аўдыт прывілеяваных карыстальнікаў
Set-AzurePrivilegedUsers -AuditOnly
```

### Інтэграцыя Intune (Новае ў v2)
```powershell
# Падключыцеся да Intune
Connect-IntuneGhost -Interactive

# Разгарніце праз палітыкі Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ Важныя Меркаванні

### Патрабаванні да Тэставання
- **Лабараторнае Асяроддзе**: Спачатку пратэсціруйце ўсе налады ў ізаляваным асяроддзі
- **Паэтапнае Разгортванне**: Паступова разгортвайце для вызначэння праблем
- **План Адкату**: Упэўніцеся, што можаце адмяніць змены пры неабходнасці
- **Дакументацыя**: Запішыце, якія налады працуюць для вашага асяроддзя

### Магчымы Ўплыў
- **Прадукцыйнасць Карыстальніка**: Некаторыя налады могуць паўплываць на штодзённыя працоўныя працэсы
- **Спадчынныя Прыкладанні**: Старыя сістэмы могуць патрабаваць пэўных пратаколаў
- **Аддалены Доступ**: Улічвайце ўплыў на законнае аддаленае адміністраванне
- **Бізнес-Працэсы**: Пераканайцеся, што налады не парушаюць крытычныя функцыі

### Абмежаванні Бяспекі
- **Эшэланаваная Абарона**: Ghost - гэта адзін узровень бяспекі, а не поўнае рашэнне
- **Пастаяннае Кіраванне**: Бяспека патрабуе пастаяннага маніторынгу і абнаўленняў
- **Навучанне Карыстальнікаў**: Тэхнічны кантроль павінен спалучацца з інфармаванасцю аб бяспецы
- **Эвалюцыя Пагроз**: Новыя метады атак могуць абысці бягучую абарону

## 🎯 Прыклады Сцэнарыяў Атак

Нягледзячы на тое, што Ghost накіраваны на распаўсюджаныя вектары атак, канкрэтная прафілактыка залежыць ад правільнай рэалізацыі і тэставання:

### Атакі Тыпу WannaCry
- **Змякчэнне**: `Set-Ghost -SMBv1` адключае ўразлівы пратакол
- **Меркаванне**: Упэўніцеся, што ніводная спадчынная сістэма не патрабуе SMBv1

### Ransomware на Аснове RDP
- **Змякчэнне**: `Set-Ghost -RDP` блакуе доступ да аддаленага працоўнага стала
- **Меркаванне**: Могуць спатрэбіцца альтэрнатыўныя метады аддаленага доступу

### Шкоднасныя Праграмы на Аснове Дакументаў
- **Змякчэнне**: `Set-Ghost -Macros` адключае выкананне макрасаў
- **Меркаванне**: Можа паўплываць на законныя дакументы з уключанымі макрасамі

### Пагрозы, Дастаўленыя праз USB
- **Змякчэнне**: `Set-Ghost -USBStorage -AutoRun` абмяжоўвае функцыянальнасць USB
- **Меркаванне**: Можа паўплываць на законнае выкарыстанне прылад USB

## 📚 Лепшыя Практыкі

### Перад Разгортваннем
1. **Задакументуйце Бягучы Стан**: Запусціце `Get-Ghost` перад зменамі
2. **Дбайна Тэсціруйце**: Правяраць у непрадукцыйным асяроддзі
3. **Стварыце План Адкату**: Ведайце, як адмяніць кожную наладу
4. **Агляд Зацікаўленых Бакоў**: Упэўніцеся, што бізнес-падраздзяленні ўхваляюць змены

### Падчас Разгортвання
1. **Паэтапны Падыход**: Спачатку разгарніце ў пілотных групах
2. **Маніторце Уплыў**: Назірайце за скаргамі карыстальнікаў або праблемамі сістэмы
3. **Дакументуйце Праблемы**: Запісвайце любыя праблемы для будучых спасылак
4. **Паведамляйце аб Зменах**: Інфармуйце карыстальнікаў аб паляпшэннях бяспекі

### Пасля Разгортвання
1. **Рэгулярная Ацэнка**: Перыядычна запускайце `Get-Ghost` для праверкі налад
2. **Абнаўляйце Дакументацыю**: Падтрымлівайце канфігурацыі бяспекі ў актуальным стане
3. **Аглядайце Эфектыўнасць**: Маніторце інцыдэнты бяспекі
4. **Пастаяннае Паляпшэнне**: Карэктуйце налады на аснове ландшафту пагроз
